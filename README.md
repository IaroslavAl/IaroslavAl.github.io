# IaroslavAl’s GitHub Pages site

This repository publishes the home page at [iaroslaval.github.io](https://iaroslaval.github.io/). The home page currently redirects visitors to the [Surebet Stake Calculator support site](https://iaroslaval.github.io/surebet-support/).

## Where to make changes

- **Home page.** Edit `index.html` here to change the redirect or replace it with a home page that links to several projects.
- **Search engines.** The root `robots.txt` points crawlers to the support site’s sitemap. Keep the `yandex_*.html` verification file at the root so Yandex Webmaster can verify this host.
- **Calculator support.** The FAQ, contact information, translations, and privacy policies live in the [surebet-support repository](https://github.com/IaroslavAl/surebet-support).
