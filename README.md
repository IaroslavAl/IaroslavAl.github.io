# iaroslaval.github.io

Root of the GitHub Pages host. It redirects to the [Surebet Stake Calculator support site](https://iaroslaval.github.io/surebet-support/) ([repository](https://github.com/IaroslavAl/surebet-support)) holds the Yandex Webmaster verification file and a `robots.txt` that points search engines to the site's sitemap, because Yandex verifies the whole host rather than a subfolder. Keep `yandex_*.html` in place, or verification is lost.
