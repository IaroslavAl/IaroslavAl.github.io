# iaroslaval.github.io

Root of the GitHub Pages host. It contains no app code:

- `index.html` redirects to the [Surebet Stake Calculator support site](https://iaroslaval.github.io/surebet-support/) ([repository](https://github.com/IaroslavAl/surebet-support)).
- `yandex_*.html` verifies the host in Yandex Webmaster, which verifies the whole host rather than a subfolder. Keep it in place, or verification is lost.
- `robots.txt` points search engines to the support site's sitemap.
