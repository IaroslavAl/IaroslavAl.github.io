# iaroslaval.github.io

Root of the GitHub Pages host. It redirects to the [Surebet Stake Calculator support site](https://iaroslaval.github.io/surebet-support/) ([repository](https://github.com/IaroslavAl/surebet-support)) and holds the Yandex Webmaster verification file, because Yandex verifies the whole host rather than a subfolder. Keep `yandex_*.html` in place, or verification is lost.
